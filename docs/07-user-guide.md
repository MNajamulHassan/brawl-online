# 07 · User Guide

## Getting started

1. Open the game link in any modern browser (Chrome, Safari, Firefox, Edge) on a phone or computer.
2. Under **Your fighter**, type a name, pick a colour and a hat. These are remembered next time.
3. Choose how to play:
   - **Quick play**: jump into a public match (one is created if none exist).
   - **Public matches**: pick one from the list.
   - **Join a private match**: type the 5-character code a friend gave you.
   - **Create a match**: choose mode, map, Public/Private, and whether bots fill empty slots.
   - **Practice vs bots**: a private match against 5 bots.

On phones, turn the screen sideways for the best view.

## Controls

| Action | PC | Phone / tablet |
|---|---|---|
| Move | W A S D or arrow keys | Drag with left thumb |
| Aim | Mouse | Drag with right thumb |
| Shoot | Hold left click | Push right thumb past the inner red ring |
| Throw distance (grenades) | Distance of the cursor from you | How far you push the right thumb |
| Swap weapon | Q or mouse wheel | **Swap** button |
| Scoreboard | Tab | **Scores** button |
| Leave | **Leave** button | **Leave** button |

## Weapons

| Weapon | Ammo | Notes |
|---|---|---|
| Pistol | Infinite | Always with you |
| Assault rifle (AR) | 30 | Fast, small spread |
| Shotgun (SG) | 6 | 7 pellets, short range |
| RPG | 2 | Explodes on impact, big splash |
| Grenades (NADE) | 3 | Thrown to where you aim, explode after ~1 s |

Weapons appear as glowing circles on the map. Walk over one to pick it up. A dashed circle means it is refilling (15 s). When your special weapon runs out you switch back to the pistol.

## Modes

- **Deathmatch**: everyone for themselves. First to 15 eliminations wins.
- **Team deathmatch**: Red vs Blue, no friendly fire. First team to 30 wins.

Rounds last up to 5 minutes. Scores show for 8 seconds, then a new round starts.

## Troubleshooting

| Problem | Fix |
|---|---|
| Badge says "Server offline" | The server may be waking up (free hosting). Wait 30–60 s and refresh. |
| "No match found with that code" | Check the code; the match ends when everyone leaves. |
| Movement feels jumpy | Check the ping in the bottom-right; Wi-Fi is usually better than mobile data. |
